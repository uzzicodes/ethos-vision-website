# Ethos Vision — Cinematic Studio Website

**Live:** https://uzzicodes.github.io/ethos-vision-website/

A luxury, 3D portfolio website for **Ethos Vision**, a studio producing cinematic showcase videos for FiveM script and MLO developers.

- WebGL lens scene and layered parallax "depth" effects
- Autoplaying video showcases with lightweight WebP posters
- Glass / gold-and-black luxury UI, smooth scrolling, responsive layout
- Hand-built with HTML, CSS and vanilla JavaScript — no framework

Built by **Muhammad Uzair** · [Portfolio](https://uzzicodes.github.io)
